# Godot Context Packer

Herramienta web ligera y 100% local para empaquetar proyectos de **Godot Engine** en un único archivo de texto (`contexto_godot.txt`), optimizado para compartir contexto completo con modelos de inteligencia artificial.

## 🌐 Usar la aplicación en vivo
Abre la herramienta directamente en tu navegador sin instalar nada:
**[Abrir Godot Context Packer](https://jarenrafael.github.io/godot-context-packer/)**

## ✨ Características
- **Privacidad total:** Todo se procesa localmente en tu navegador; ningún archivo sale de tu computadora.
- **Filtros por extensión:** Elige exactamente qué archivos incluir (`.gd`, `.json`, `.tscn`, `.tres`, `.godot`, entre otros).
- **Optimización de tokens:** Recorta automáticamente líneas serializadas largas en escenas y recursos para no saturar el límite de contexto.
- **Exportación en 1 clic:** Descarga el archivo `.txt` listo o cópialo directo al portapapeles.

## 🚀 Cómo usarlo
1. Entra al enlace de la aplicación.
2. Selecciona la carpeta raíz de tu proyecto de Godot.
3. Verifica el medidor de tokens y haz clic en **Descargar contexto_godot.txt**.
